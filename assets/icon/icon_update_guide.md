# Güncellenmiş App Icon Rehberi

## 🎯 **Hedef:**
- Mavi arka plan (#4285F4)
- Beyaz ev/pencereli yapı
- Geri dönüşüm oku (beyaz çizginin üzerinde)
- 3 yatay çizgi (içerik temsili)

## 🎨 **Tasarım Özellikleri:**

### **Ana Elementler:**
1. **Mavi Arka Plan:** #4285F4 (Google Blue)
2. **Beyaz Ev Yapısı:** Pencere slatları ile
3. **Geri Dönüşüm Oku:** Dairesel, beyaz, net
4. **İç Çizgiler:** 3 yatay beyaz çizgi

### **Renk Paleti:**
- Arka plan: #4285F4 (Mavi)
- Ana elementler: #FFFFFF (Beyaz)
- Vurgu: #E3F2FD (Açık mavi)

## 📐 **Boyutlar:**
- Ana boyut: 1024x1024 piksel
- Format: PNG
- Arka plan: Dolu mavi
- Padding: Kenarlardan %10 boşluk

## 🔄 **Geri Dönüşüm Oku:**
- Dairesel ok yolu
- Beyaz renk
- Net ve okunabilir
- Ev yapısının üzerinde

## 📋 **Adımlar:**

### 1. Icon Hazırlama:
- SVG dosyalarını referans alın
- PNG formatında 1024x1024 oluşturun
- Mavi arka plan kullanın

### 2. Dosya Yerleştirme:
- `icon.png` olarak kaydedin
- `assets/icon/` klasörüne koyun

### 3. Icon'ları Oluşturun:
```bash
dart run flutter_launcher_icons
```
