# App Icon Assets

Bu klasör GarageLoop uygulamasının app icon dosyalarını içerir.

## Dosyalar:
- `icon.png` - Ana app icon (1024x1024)
- `icon_foreground.png` - Android adaptive icon foreground (108x108)
- `icon_background.png` - Android adaptive icon background (108x108)

## Boyutlar:
- iOS: 1024x1024, 180x180, 167x167, 152x152, 120x120, 87x87, 80x80, 76x76, 60x60, 40x40, 29x29
- Android: 512x512, 192x192, 144x144, 96x96, 72x72, 48x48
- Web: 512x512
- Windows: 256x256
- macOS: 1024x1024
